# 07: Safely apply the complete workflow to an existing Collection

**What to build:** An author can run the integrated YAML, Note Type, Template, styling, tag, and new-managed-Card placement workflow against an existing Collection through a guarded command. It previews/rehearses on a temporary consistent copy, then permits explicitly approved application only with Anki Desktop closed. Verify the complete workflow against an existing tool-created sandbox Collection, never a personal Collection. No backup, restore, or recovery-package mechanism is built. Existing Card Deck placement is preserved without mismatch reporting.

**Blocked by:** 05 — Apply Note Types, Templates, and shared styling; 06 — Verify new managed Card placement in linked Decks.

**Status:** resolved

**Verification environment:** Use the dedicated `.venv`, tool-created sandbox Collections with matching manifests, and temporary isolated fixtures documented in [`tools/headless_import/exploration.md`](../../../tools/headless_import/exploration.md). That environment supports end-to-end acceptance, not just preliminary exploration. Historical importer backups, missing-Deck creation, and existing-Card movement are not product requirements.
